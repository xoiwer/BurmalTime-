# BurmalTime

Премиальный адаптивный музыкальный frontend на React + Vite + TypeScript.

## Что внутри

- Главная с hero-анимацией, подборками и каталогом.
- Каталог с поиском, категориями и сортировкой.
- Страницы композиций, 404, избранное и история.
- Нижний HTML5 Audio-плеер: play/pause, предыдущий/следующий, перемотка, громкость, shuffle, repeat, компактный режим.
- Добавление аудиофайлов с устройства без сервера.
- Оригинальные SVG-обложки, логотип, фон и референс из `public/assets` и `reference`.
- Избранное и история хранятся в LocalStorage.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно `http://localhost:5173`).

## Production-сборка

```bash
npm run build
npm run preview
```

Готовая версия сайта появится в `dist/`.

## Как подключить собственную музыку

**Способ 1 — добавить аудио в проект:**

1. Положи свой аудиофайл в `public/audio/`, например `my-mashup.mp3`.
2. Открой `src/data/tracks.ts`.
3. У нужной композиции добавь `audio: '/audio/my-mashup.mp3'` и `demo: false`.
4. Укажи настоящее название, автора и длительность.

**Способ 2 — загрузить с интерфейса:**

Открой «Добавить трек», выбери аудиофайл и добавь его в каталог. Файл воспроизводится локально через HTML5 Audio API и не загружается на сервер. Такое добавление действует в текущей вкладке/сеансе браузера; после перезагрузки страницы его нужно добавить снова. Для постоянного хранения добавляй аудио в `public/audio/` и каталог проекта.

Используй только собственные записи или аудио, на использование которых у тебя есть разрешение.

## Публикация

### Vercel

1. Создай GitHub-репозиторий и загрузи в него содержимое папки проекта.
2. На Vercel выбери **Add New → Project** и подключи репозиторий.
3. Framework preset: **Vite**. Build command: `npm run build`. Output directory: `dist`.
4. Нажми Deploy. При следующих push в основную ветку Vercel будет обновлять сайт.

### Netlify

1. Загрузи проект в GitHub.
2. В Netlify выбери **Add new site → Import an existing project**.
3. Build command: `npm run build`; Publish directory: `dist`.
4. Нажми Deploy.

Для SPA добавлен `public/_redirects`, чтобы прямые ссылки на страницы приложения открывались корректно.

## Важные ограничения первой версии

- Это frontend без аккаунтов, сервера и общей облачной библиотеки.
- Локально загруженные аудиофайлы не видны другим посетителям.
- В каталоге нет выдуманных счётчиков прослушиваний.
- Демо-карточки не содержат реального звука, пока ты не подключишь легальный аудиофайл.
- Для постоянной общей библиотеки, аккаунтов и статистики в будущем понадобится backend или отдельное хранилище.
